# 🎓 Student Internship Board Portal

A responsive, secure, and production-ready full-stack web application designed to connect students with internship opportunities.

## 🚀 Live Demo & Links
- **Live Application:** https://amruthakonchada2006-rgb.github.io/intrenship-board/
- **GitHub Repository:** https://github.com/amruthakonchada2006-rgb/intrenship-board

## ✨ Features & User Journey
- **Browse Internships:** Explore curated opportunities with location and role details.
- **Application Form:** Smooth client-side and server-side validated application submission.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
- **Feedback Indicators:** Real-time loading spinners and interactive error feedback.

## 🛡️ Security & Performance Enhancements
- **Helmet.js:** Secures HTTP headers against web vulnerabilities.
- **Express Rate Limit:** Prevents API abuse and brute-force attacks.
- **Express Validator:** Input sanitization and error handling.
- **Health Check Endpoint:** `/health` endpoint for monitoring backend status.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+)
- **Backend:** Node.js, Express.js
- **Deployment:** GitHub Pages (Frontend static hosting)
